# 🩺 Diabetes Prediction System using Machine Learning

## 📌 Project Overview
This project is a Machine Learning-based Diabetes Prediction System developed using Python and Logistic Regression.

The model predicts whether a person has diabetes based on medical details such as:
- Glucose Level
- Blood Pressure
- BMI
- Insulin Level
- Age
- Pregnancies

The project uses the Pima Indians Diabetes Dataset and Logistic Regression algorithm for prediction.

---

# 🚀 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Logistic Regression
- VS Code

---

# 📊 Dataset Information

The dataset contains the following columns:

| Feature | Description |
|----------|-------------|
| Pregnancies | Number of pregnancies |
| Glucose | Glucose level |
| BloodPressure | Blood pressure value |
| SkinThickness | Skin thickness |
| Insulin | Insulin level |
| BMI | Body Mass Index |
| DiabetesPedigreeFunction | Diabetes hereditary function |
| Age | Age of patient |
| Outcome | Diabetes result (0 = No, 1 = Yes) |
